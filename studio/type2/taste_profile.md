# Type‑2 Reel Taste Profile

Persistent editorial notes for future Type‑2 episodes; this is a written preference profile, not a trained model.

- Format: short-form “ranking best fail moments” style, consistent with EP6; usually five distinct clips per reel, about 15–20 seconds total.
- Pick varied, visually legible funny fails; do not assume a prior episode’s theme carries over. Avoid reusing EP7 footage.
- Prioritize a clear setup and payoff; avoid weak/ambiguous moments, severe injury, gore, unnecessary zooms, and speed-ups.
- Audio: no source songs in preview or final. Mute/replace clips if music separation is uncertain; retain natural speech/laughter only when clean. Use the series’ own background track and established Type‑2 impact SFX, “I got this” hits, and chicken+scream.
- Prefer source footage without baked-in captions/text/watermarks where possible; reject or reframe a clip if such overlays distract from the action.
- Never reuse the same source clip in two reels in one batch. Prefer one continuous incident per source; avoid compilation footage that cuts between unrelated moments.
- Each fail clip must show setup, the fall/fail, and a brief aftermath. Reject any trim that begins mid-action or ends before the payoff, even if that means using fewer than five clips.
- Keep one clearly named active final per episode in Drive, preserve prior episodes/deliverables, and continue episode numbering.
